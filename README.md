# JVS Website

React + Vite website for Jyoshna's Versatile Stability (JVS).

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Push this project to GitHub, then import the repository into Vercel.

Framework preset: Vite
Build command: `npm run build`
Output directory: `dist`

Vercel normally detects the Vite setup automatically.

## Content source

The page content is based on the supplied JVS brochure. Replace or add approved images/logos in `public/` if the organisation provides them.
